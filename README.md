# Clinical Trial SAS Programming, CDISC & Power BI Portfolio

**Clinical SAS | SDTM | ADaM | TLFs | Data Quality | Power BI**

A hands-on clinical programming and data analytics portfolio developed using a simulated Phase IIb clinical trial study of Analgezia HCl for chronic pain. This project demonstrates practical learning in clinical data transformation, CDISC standards, analysis datasets, statistical reporting, validation, and clinical data visualization.

## About Me

B.Pharm graduate and SAS Certified Specialist in Base Programming Using SAS 9.4, with a certification score of 938/1000. Final-semester second ranker with a focused interest in clinical data management, clinical SAS programming, and statistical programming.

## Project Overview

- **Study:** Simulated Phase IIb chronic pain clinical trial
- **Design:** Randomized, double-blind, multicenter, placebo-controlled
- **Programming:** Base SAS 9.4
- **Data standards:** CDISC SDTMIG v3.4 and ADaMIG v1.2
- **Visualization:** Microsoft Power BI
- **Validation tool:** Pinnacle 21 Community

## Skills Demonstrated

- SAS DATA step, PROC SQL, sorting, merging, and data manipulation
- Clinical domain mapping and SDTM dataset preparation
- ADaM subject-level and adverse-event analysis datasets
- Treatment-emergent adverse event programming concepts
- Clinical tables, listings, and safety summaries
- Dataset validation and SAS log review
- XPT conversion and CDISC conformance review
- Power BI dashboard design and clinical KPI visualization

## Project Deliverables

### 1. SDTM

Domains created or mapped in the project:

- DM — Demographics
- AE — Adverse Events
- EX — Exposure
- LB — Laboratory Tests
- XP — Project-specific domain
- SUPPDM — Supplemental Demographics

**Validation status:** The DM dataset was validated using Pinnacle 21 Community and converted to XPT. Do not interpret this as validation of every listed domain.

### 2. ADaM

- **ADSL:** Subject-level analysis dataset
- **ADAE:** Adverse-event analysis dataset
- Analysis population flags and treatment-related derivations
- Safety analysis preparation

### 3. Tables, Listings and Figures (TLFs)

SAS programs developed for clinical reporting exercises, including:

- Demographics and subject population summaries
- Treatment-emergent adverse events
- Serious adverse events
- Adverse events by system organ class and preferred term
- Listings and safety summaries

### 4. Power BI Clinical Trial Dashboard

An interactive dashboard project using ADSL and ADAE data, designed to explore:

- Subject population and treatment groups
- Demographic characteristics
- Safety population and adverse-event summaries
- Treatment-emergent adverse-event severity

Refer to the dashboard screenshots included in this repository. The displayed results are for educational analysis of the project dataset, not clinical conclusions.
